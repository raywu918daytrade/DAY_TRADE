# ret5_pullback_reversal（做多，規則驗證）

早盤 ret5 紅K 且相對昨收大漲 → m5 拉回陰線未破首根 m5 低點 → 下一根 m5 陽線實體 K 做多。

## 鎖定

| 條件 | 規則 |
|--|--|
| 母體 | `stock_universe_2000`（~1877，排除 0050 交易） |
| 上漲 | ret5 vs 昨收 ≥ 3%，且 **m5@09:05 為紅K**（close &gt; open） |
| 參考低點 | 首根 m5（09:05）low = `m5_1_low` |
| 拉回／反轉 | **僅 m5_std**：陰線（c&lt;o）且 low &gt; m5_1_low → 下一根陽線實體（body≥50%） |
| 時間 | 陰／陽收盤皆 &lt; 09:30；進場 = 陽線 close 且 &lt; 10:00 |
| ATR | 進場分鐘 m1 atr5 ≥ p99（0.01095） |
| 標籤 | 做多三分類 TB ±3%；最多 30 分（6 根 m5）；同根先 TP |
