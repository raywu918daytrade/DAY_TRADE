# prev_bear_m5_short（鎖定）

小樣表現最好的一組：**不用 atr5**、對稱 ±3%。

## 鎖定定義

| 條件 | 規則 |
|--|--|
| 母體 | `tick_universe` 400 支，交易排除 0050 |
| 昨收跌＋實體 | 昨日 `close < open` 且 `(open−close)/open ≥ 5%` |
| 今開高 | `open/昨收 − 1 ≥ 2%` |
| 大盤 | 當日 0050 `open < prev_close` |
| 今日 m5 跌 | 首根 `m5_std@09:05`，`close < open` |
| 進場 | 09:05 收盤做空 |
| 出場 | 做空 TB **±3%**；未觸 → 持有 30 分（6 根 m5）收盤平 |
| 濾網 | **無 atr5** |
