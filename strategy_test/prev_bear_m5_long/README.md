# prev_bear_m5_long

與 [`prev_bear_m5_short`](../prev_bear_m5_short/) **相同硬過濾**，進場改 **做多**（方向對照）。

## 鎖定定義

| 條件 | 規則 |
|--|--|
| 母體 | `tick_universe` 400 支，交易排除 0050 |
| 昨收跌＋實體 | 昨日 `close < open` 且 `(open−close)/open ≥ 5%` |
| 今開高 | `open/昨收 − 1 ≥ 2%` |
| 大盤 | 當日 0050 `open < prev_close` |
| 今日 m5 跌 | 首根 `m5_std@09:05`，`close < open` |
| 進場 | 09:05 收盤 **做多** |
| 出場 | 做多 TB ±3%；未觸 → 持有 30 分 |
| 濾網 | 無 atr5 |

### 放大 2024-01～2026-07

同條件下做多幾乎是做空的鏡像翻轉 → 方向性成立，不是隨機震盪。
