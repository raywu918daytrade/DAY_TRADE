# sr_vwap_break_day

當日 1 分K：壓力在上、支撐在下。統計「突破支撐＋VWAP」與「跌破壓力＋VWAP」之後的當日勢。

## 定義摘要

| 項目 | 規則 |
|------|------|
| 母體 | `tick_universe` ~400 檔 |
| 壓力/支撐 | 與圖上同一套包絡（三角 pivot + 最近 3 峰/3 谷外側連線）。只用 **D 之前** 日K（最多 120 根），取最後一根日K 上的線價，當日 m1 當水平線。壓力在上、支撐在下 |
| VWAP | `cum(close×volume)/cum(volume)`，每天開盤重算 |
| 突破 | 收盤變號（前一根在線一側、這一根收在另一側；above = close ≥ 線） |
| 上 | **突破支撐**（由下往上穿越支撐）**且** VWAP 向上；訊號K = 兩者較晚那根 |
| 下 | **跌破壓力**（由上往下穿越壓力）**且** VWAP 向下；訊號K = 兩者較晚那根 |
| 每方向 | 當日該方向只取第一組，避免來回穿越 |
| 漲跌 | 上：`(收盤/訊號價)-1`；下：空方 `-(收盤/訊號價-1)` |
| 站穩 | 上：收盤仍 ≥ 支撐且 ≥ 當日最終 VWAP；下：收盤仍 < 壓力且 < 最終 VWAP |
| 摩擦 | mean_net = mean − 0.45% |
| 時段 | 09:00–10:00 / 10:00–12:00 / 12:00–13:30 |

## 跑法

```bash
python -m strategy_test.sr_vwap_break_day.verify \
    --start_date 2026-07-01 --end_date 2026-08-14
```
